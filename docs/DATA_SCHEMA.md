# Data schema

Generated by `tools/make_schema_doc.py` from the column headers of the r6 release (`docs/data/schemas_r6.json`,
written by `tools/dump_schemas.py`). A description is given only for columns whose meaning the pipeline code or the
release documentation states; the remaining columns are listed with their type and nothing else.

## `sar_all.parquet`

All formal SAR records with provenance, quality flags and splits (one measurement per row). 603,908 rows, 86 columns.

| Column | Type | Meaning |
|---|---|---|
| `source` | string | Extraction run: `USPTO_MOL` (original extraction) or `USPTO_MOL_RECOVERY` (recovery run) |
| `source_record_id` | string | Extraction record id; unique per row of `sar_all`. In task files, rows merged from repeated measurements join the ids with ` | ` in measurement order |
| `Patent` | string | Patent number with kind code (e.g. US10899738B2) |
| `patent_core` | string | Patent number without kind code; the patent key across tables |
| `year` | double | Grant year (from the year directory of the archive) |
| `priority_date` | string | Priority date: earliest priority claim, else PCT filing date, else US filing date; the grant year is used as an upper bound when none of the three exists |
| `priority_source` | string | Where `priority_date` comes from |
| `first_public_date` | string | First public date: the earliest of US application publication, PCT publication and grant date; left empty (not estimated) when none exists |
| `first_public_year` | int64 | Year of the first public date |
| `first_public_source` | string | `us_application` / `wo` / `grant` / `none` |
| `Target` | string | Assay label as printed in the patent (verbatim) |
| `target_label` | string | Cleaned label (case and punctuation normalised), used for grouping and display |
| `Activity Type` | string | Endpoint: IC50, Ki, Kd, EC50, ... |
| `Relation` | string | Relation sign (`=`, `>`, `<`, ...) |
| `Value` | double | Value in the original unit |
| `Unit` | string | Unit |
| `value_nM` | double | Value converted to nM |
| `pAct` | double | 9 - log10(value_nM), only for exact values within 2-13; in task files the median over repeated measurements |
| `SMILES` | string | Parent molecule (largest organic fragment, neutralised) |
| `InChIKey` | string | InChIKey of the parent molecule |
| `SMILES_as_drawn` | string | Structure as drawn in the patent |
| `InChIKey_as_drawn` | string | InChIKey of the structure as drawn |
| `scaffold` | string | Murcko scaffold |
| `heavy_atoms` | int64 | Number of heavy atoms |
| `compound_alias` | string | Compound number printed in the patent |
| `activity_locator` | string | Cell holding the activity: table / tgroup / row / column, e.g. `TABLE-US-00007/tgroup-2/row-152/column-8` |
| `activity_header` | string | Verbatim header of that column |
| `raw_value` | string | Verbatim text of the cell |
| `structure_file` | string | Original MOL file of the compound (path inside the archive) |
| `group_id` | int64 | Group = one patent x one assay label x one endpoint |
| `family_id` | double | Patent family (clustered by shared molecules, not INPADOC); numbered by the smallest `group_id` in the family |
| `uniprot_accession` | string | UniProt accession of the target (from the target mapping) |
| `mapped_identity` | string | Mapped target identity (gene name; non-protein assays are written `ORG:species|name`) |
| `target_class` | string | Target class |
| `target_organism` | string | Target organism |
| `is_human_target` | bool | Whether the target is human |
| `confidence` | string | Confidence of the target mapping: high / medium / low / none |
| `measured_in_cells` | string | The assay was run in cells |
| `mappability` | string | Judgement of whether the label can be mapped to a target |
| `mapping_run` | string | Target-mapping run (v1 / v2) |
| `is_affinity` | bool | Endpoint is an affinity type (IC50, Ki, Kd, EC50) |
| `is_exact` | bool | Exact value (relation `=`, and not derived from an A/B/C legend) |
| `is_categorical_derived` | bool | Threshold or interval derived from an A/B/C legend, not a printed number |
| `is_druglike` | bool | Drug-like (heavy-atom count, element composition, ...) |
| `target_mapped` | bool | Target mapped at high or medium confidence |
| `is_biochemical` | bool | Biochemical (cell-free) assay |
| `replicate_disagrees` | bool | Repeated measurements of one compound differ by more than 1 log; the pair is not used |
| `is_family_representative` | bool | Whether this group represents its patent family |
| `group_n_molecules` | double | Number of distinct molecules in the group (recounted after row hold-outs) |
| `group_pAct_min` | double | Smallest pAct in the group |
| `group_pAct_max` | double | Largest pAct in the group |
| `group_pAct_range` | double | Largest pAct difference within the group |
| `group_pAct_std` | double | Standard deviation of pAct within the group |
| `group_n_distinct` | double | Number of distinct pAct values in the group |
| `group_is_gradelike` | bool | Values in the group look like grades (A/B/C, ...) |
| `group_median_heavy_atoms` | double | Median heavy-atom count of the molecules in the group |
| `group_is_fragment_suspect` | bool | Median heavy-atom count of the group below 16: a substituent table |
| `group_unit_suspect` | bool | Unit or table-layout problem |
| `group_unit_issue` | string | Reason for `group_unit_suspect` (one of the six unit checks) |
| `group_is_duplicate` | bool | Duplicate group: the same table read twice |
| `group_duplicate_of` | int64 | The kept group a duplicate group points to |
| `group_label_uninformative` | bool | The label does not point to any assay |
| `label_repaired` | bool | The label was a bare number; the group was rebuilt from the header text |
| `pair_under_adjudication` | bool | (patent, target) pair on which the two annotators of the validation sample disagreed |
| `pair_validated_error` | bool | (patent, target) pair judged wrong by both annotators |

| `n_stereocentres` | int64 | Number of stereocentres |
| `has_undefined_stereo` | bool | At least one stereocentre is undefined |
| `is_isotope_labelled` | bool | Isotope-labelled (mostly deuterated) |
| `covalent_warhead` | string | Contains a covalent warhead (acrylamide, chloroacetamide, vinyl sulfone, boronic acid, ...) |
| `is_bro5_size` | bool | More than 50 heavy atoms (macrocycles, PROTACs, ...) |
| `value_beyond_assay_range` | bool | pAct above 11 or below 3, mostly extrapolations or tight-binding limits |
| `is_adme_safety_target` | bool | Off-target panels: CYP inhibition, hERG, Nav1.5, Cav1.2, transporters, ... |
| `in_public_data` | bool | The (molecule, target) pair occurs in BindingDB or ChEMBL |
| `molecule_is_new` | bool | The molecule is not in BindingDB / ChEMBL |
| `patent_is_new` | bool | The patent is not cited by BindingDB / ChEMBL |
| `split_time` | string | Main split: test when the earliest priority year of the component is at or after the cutoff and every patent was granted in 2020 or later; 15% of the rest random valid |
| `split_time_grant` | string | Comparison: test when the earliest grant year of the component is 2021 or later (rule of an earlier version) |
| `split_random` | string | Random 70/15/15 over components |
| `split_scaffold_mol` | string | By molecular scaffold (regression) |
| `split_scaffold_group` | string | By the dominant scaffold of the group (ranking) |
| `test_tier` | string | Test groups only: `novel` = no (molecule, target) pair of the group is in the public databases; `reference` = the rest; `unscored` = no high/medium-confidence target |
| `structure_repair` | string | Structure-repair rules applied to the stored structure: `NH`, `group`, `nitrile`, `text`, joined by `;`; empty when unchanged |
| `SMILES_before_repair` | string | SMILES stored before the structure repair |
| `InChIKey_before_repair` | string | InChIKey stored before the structure repair |
