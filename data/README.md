# Data

Dataset files are not tracked in git. Download **PatBench v1.0** from figshare (CC BY 4.0):

- **DOI:** <https://doi.org/10.6084/m9.figshare.34925475>

Place the downloaded files in this directory, then unpack and verify:

```bash
patbench unpack data --out /tmp/patbench_data
patbench verify-release /tmp/patbench_data
```
