Target-mapping review · PatBench test groups

groups: the test groups of rank_ic50 and rank_ki_kd, plus test groups of the other tasks (rank_highcontrast, rank_complex_mutant, rank_ec50) that are not among them. No verdict is pre-filled; every judgement is the reviewer's.

How to review (30 seconds)

Each card is one test group, i.e. one IC50 or Ki/Kd table of one patent. There is one question to answer: is the protein measured in this table the UniProt entry we mapped it to?

  1. Left column: the label printed in the patent and the patent title; use them to decide which protein was actually measured.
  2. Middle column: the protein we mapped it to (gene, protein name, species, mutation). Watch isoforms (α/β/δ/γ), species, wild type versus mutant, and complex subunits.
  3. If unsure, open the patent number (Google Patents) to read the table header, or the UniProt accession to check the entry.
  • Correct: protein, species and isoform are all right.
  • Wrong: any of them is wrong. Give the reason in the note and, if you can determine it, the correct UniProt accession.
  • Unsure: the patent text does not settle it. Say in the note what information is missing.

The "Why review" box at the top of each card lists the doubts raised by the automatic checks. "Label does not name the target" is a crude string comparison and gives false alarms for Greek letters (δ versus delta), abbreviations and aliases; "public cross-reference differs" may be an error on the side of the public database. Both are clues, not conclusions.

This page reviews only the target mapping, not molecular structures or values. Shortcuts: j/k next/previous card, 1/2/3 = correct/wrong/unsure, 0 clear. Progress is stored in this browser; export the TSV regularly.

Data: target_review_test.tsv of the release; the additional fields come from the same release's target_audit.parquet and groups.parquet. The exported TSV keeps the 20 columns of the original table; reviewer_verdict holds correct / wrong / unsure, reviewer_note the note, and one column reviewer_corrected_uniprot is appended. This page does not modify the dataset. Cards marked "not in the original table" come from eval_support/target_review_test_other_tasks.tsv (test groups of the other tasks, with the same fields), so the exported TSV has one row per card.
